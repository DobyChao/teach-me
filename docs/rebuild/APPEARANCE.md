# 外观与表现层

2026-10-19，来源：用户要求亮暗色切换、未来主题及桌宠。当前实现与后续扩展分开记录，ADR-017说明取舍。

## 本轮交付

设置中的浅色、深色、跟随系统先在设置窗口预览，保存成功后所有应用窗口同步；取消/关闭丢弃未保存预览，保存失败保留表单。旧配置缺少appearance时保持原深色，不覆盖截图、语音等偏好。系统模式由宿主nativeTheme解析，Renderer只接收解析后的colorScheme。

shared/appearance.ts是内建主题注册表：id、显示名及light/dark两套完整语义token。新增内建主题只需添加配色、注册id和验收；组件使用bg/surface/text/muted/accent/on-accent等语义颜色。色阶与主题id独立，未来增加主题不再复制整套组件。当前只提供冷灰/玫粉一套主题，不显示不可用的主题/桌宠按钮。

面板、设置、画板工具栏统一应用配色。画板切换theme不重建编辑器、不改用户笔迹及撤销历史；透明导出遵循当前编辑器theme。Agent屏幕指引的文字保持浅色加深色描边，以适应外部应用背景，不能把窗口浅色正文直接用到外部屏幕。

## 主题包后续边界

先扩展为声明式manifest（id、名称、浅深配色、可选本地资产），校验完整token与色值、体积和对比度，再设计显式导入/预览/回滚。当前没有实现外部主题导入；不能把未来包当成可执行CSS/JS或新增IPC权限。安装与卸载不得改变会话、录音或截图偏好。

## 桌宠后续边界

桌宠与颜色主题分开：配色由theme控制，形象/动作由独立companion表现层控制。表现层消费现有只读教学状态（空闲、等待、思考、录音、需要注意），不拥有会话、麦克风或新消息输入框；唤起仍复用唯一教学输入面。

后续先确定可关闭/隐藏、位置/穿透、默认形象、本地sprite或矢量资产、减少动态效果、闲置资源预算，以及如何表达断连/错误。若增加独立窗口，沿用捕获保护、自身截图排除与sender白名单。当前未交付宠物动画或资源包，用户尚未选择具体形象，不引入云端账号或远程素材加载。

## 动效契约

视觉过渡220ms，由Chromium的transform/opacity/clipPath完成。宿主只分配起终点包围范围，结束再收紧原生窗口；无逐帧setBounds。保留同一HWND和textarea，文字按目标宽度布局，不整体缩放文字。重定向使用当前视觉几何，递增transition id防旧完成回调生效；重复目标不重启，Renderer完成通知收尾，500ms兜底避免永久占据透明范围。

减少动态效果直接切换。透明包围范围在过渡期间可能短暂接收鼠标，这是Windows透明窗口限制；正常220ms收尾，Renderer异常时最多兜底500ms。仍需单独验收第三方远控、高刷新率、跨屏DPI和设备负载，不能由一组帧采样保证所有机器主观流畅。

后续收尾/拖动故障由ADR-018修正：固定目标盒做FLIP且终点identity；拖动固定逻辑宽高，带版本的测高跨边界作废。当前契约和公开参考见[MOTION.md](MOTION.md)，历史T21中段帧采样不代替T22全过程验证。
