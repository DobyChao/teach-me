## 实现

- package新增`tma` bin，保留`teach-me-agent`别名；`npm run setup`显式构建、全局link、安装skill。CLI以自身模块路径找App和协议，不依赖调用者cwd；不在npm ci/postinstall隐式改Agent配置。
- `tma help/--help/--version/protocol`，`skill install/status/path`与兼容`install-skill`；支持CODEX_HOME和自定义技能父目录。缺值、未知安装选项、多余参数、未支持宿主均拒绝，不误落到默认目录。
- `skills/teach-me/SKILL.md`为随Git维护的教学技能；指导稳定client、持续wait、自动ack、看所有截图、截图坐标和审批/断连恢复。协议通过`tma protocol`按需读取，避免复制长文漂移。App复制连接说明新增skill/tma入口，保留未注册时的绝对node路径。
- 安装器复制技能并保存来源/hash标记，只更新自己拥有且未修改的内容；同名外来技能、被改过的安装、目录junction均拒绝。原子替换，不覆盖额外的个人文件。`skills/`已纳入项目上下文摘要，修改技能会触发context过期。
