# T45 · 画板开关全局快捷键

2026-10-24。用户要求打开/关闭画板也有快捷键。现状：热键固定为 Ctrl+Alt+W（唤醒输入/按住说话）与 Ctrl+Alt+H（指引显隐），画板只能点面板工具按钮或画板内"完成画板"按钮开关（`edit` 动作）。目标（R36/A42）：新增 Ctrl+Alt+B 切换画板编辑态，走与按钮完全相同的 `edit` 路径，含义进入 tooltip、设置提示与协议热键清单。

实现四处：main.ts 热键注册表加 `['Control+Alt+B', () => action({ type: 'edit', on: !editing })]`，复用既有循环的 quitting/panelRecovering 拦截与注册失败报占用（"快捷键 … 被占用"）；edit 动作本身零改动，打开时面板转输入档、画布由穿透转接收鼠标并按序聚焦画板（前台→show→focus→原生activate→webContents.focus），关闭时恢复穿透并 activate 原外部前台，与按钮一致。文案三处：Panel 画板按钮 title、SettingsView 快捷键提示行、UserBoard"完成画板"按钮 title；AGENT-PROTOCOL 已知限制热键清单同步为 W/H/B 三键。

验证：npm run check 通过（plan/context/boundaries/format/126项测试/构建）。动作路径为Electron宿主侧，globalShortcut 真实注册与按键行为无纯Node覆盖；Windows 真实按键开关画板、焦点/穿透切换与被占用时的报错观察 pending，不以代码审阅替代（A42）。热键在面板恢复期被统一拦截，与 W/H 行为一致，未单独放行。
