# T21 · 动效合成层、设置外观与主题基础

2026-10-19。用户纠正：T20仍感觉卡顿，系统标题框突兀，希望亮暗色及后续主题/桌宠。本轮先交付浅深/系统与主题token入口，桌宠独立表现层方案写入工程，不默认实施常驻宠物。

不沿用T20的“中间原生帧存在”作为流畅证据。设计取舍见ADR-017，外观/主题/桌宠后续边界见[APPEARANCE.md](../APPEARANCE.md)。

## 交付

- 220ms合成层形变：宿主保留同一HWND，只分配包围范围和收尾；Renderer使用transform/opacity/clipPath呈现，不缩放文字。重定向从当前视觉几何开始，重复目标不重启，旧transition id完成无效；减少动态效果直切，Renderer异常500ms兜底收紧。
- 设置为不透明无框普通窗口，同色标题、右上角关闭、固定保存/取消，保留原生边缘调整尺寸。标题用Pointer Capture限定拖动动作；不传句柄，不开放任意IPC，只有设置sender可拖设置。关闭清理拖动id，晚回调忽略；使用固定客户区尺寸防125%缩放下累积放大，手动调整尺寸后更新基准。
- 浅色/深色/跟随系统，局部预览、保存后跨窗口应用。旧配置保持原深色及其他偏好；语义token注册表支持后续内建主题。画板随配色切换，原图元和撤销历史保留；Agent外部指引文字仍有独立描边。
- 桌宠的表现层边界和后续步骤已进入项目；本轮没有交付宠物资产/动作包或外部主题导入，也没有放不可用按钮。

## Windows现场操作与修正

Computer Use原生点击胶囊、更多工具、设置，实际看到新设置没有系统白色标题框，标题/关闭和正文同色。原生点击浅色按钮后，设置呈浅色预览，背后的主面板仍深色；点右上角关闭返回教学面板，不退出应用。没有改隐私、截图选项或开启麦克风。

系统app-region拖动实验仍未移动，未把它记为通过。改为指针拖动后，设置从x704/y212实际移动到854/282，再向左移动到754/282，主面板保持360×112及原HWND。此时发现窗口尺寸每次移动增大约4 DIP；改用客户区后又通过多手势回归定位1 DIP取整累积，最终固定客户区基准、只在手动调整尺寸后刷新。最终宿主回归连续6次move和5个独立拖动手势，位置增量正确，客户区尺寸误差不超过1 DIP，不再累积；拒绝面板sender拖设置、释放后的晚回调无效。最终尺寸基准修正由Windows Electron原生几何回归验证，原生鼠标观察对应相同的指针事件路径，不冒称系统拖动区已恢复。

仅停止自己的隔离实例，正常用户实例/草稿/画板没有重启或清理。

## 失败经验与未覆盖项

- 首次外观回归误用了并不存在的测试editor接口；改用实际工具栏和指针。又把Excalidraw浅色误写为theme--light，查库发现只有深色标记；修正为非theme--dark后通过。没有为测试增加生产editor接口。
- 固定到底部的CSS在125%缩放下可能产生不足1 DIP的小数边界，旧mini严格bottom>innerHeight断言误判。统一采用现有布局回归的1像素容差；超出该范围仍失败，不用延长等待掩盖裁切。
- 保存失败和sender拒绝均为主动负例，最终passed；Vite原有大分块提示仍存在。
- 真实OS配色改变、不同DPI跨屏拖动/调整边缘、高刷新率/持续远控、IME与麦克风完整矩阵仍分别由原任务验收。T14历史进程退出根因没有因此定位。桌宠具体形象/资产和外部主题导入尚未实施。
