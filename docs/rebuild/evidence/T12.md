# T12 画图前台与快捷键生命周期

日期：2026-10-17。Windows、Electron 44。

修复：停止按输入状态调用 Electron setFocusable、停止按输入状态添加/移除任务栏入口；维持创建时的激活代理，通过 NOACTIVATE 位控制聚焦前截图。非最小化浮窗在外部前台变化时仅提高 Z 序。禁止常规最小化，快捷键能恢复确实隐藏/最小化的原窗口。普通 focus 不足时原生激活兜底，并聚焦 WebContents。增加不含正文的窗口显隐/最小化/焦点日志。

验证：

- `node scripts/smoke.mjs`：24 项通过。连续输入/取消/设置/画布三轮，setFocusable 与任务栏重建调用为 0；原生窗口样式和窗口身份不变，原有 CLI 两轮收发通过。
- `node scripts/window-lifecycle.mjs` + computer-use：激活已打开的画图，连续三轮 Ctrl+Alt+W，前两轮 Escape，第三轮真实输入“窗口前台切换测试”并 Enter；CLI 收到并回复。lifecycle-result.json 为 passed，show/hide/minimize/restore/created/activation/taskbar 全为 0，captures=3，captureBeforeFocus=true；每轮检查了原生窗口焦点与 textarea 焦点。窗口 HWND 与 renderer PID 均不变；面板持续可见且未最小化。截图使用注入合成图，不采集画图画布。现场视觉观察面板仍在画图之上。
- 初次监测在准备阶段读取两份不同时刻的样式/可聚焦快照，误报不一致，改为持续监控显隐、阶段稳定后核对样式。真实键盘发现只有面板外观、焦点未稳定进入输入框；加原生焦点兜底后重新完整执行三轮，第三轮真实文字输入与发送通过。
- `npm run check` 通过：规划、边界、格式、39 个测试、类型与构建全部通过。

范围与限制：computer-use 明确禁止 Windows 键组合和运行对话框；直接启动 Paint 的工具授权又超时，所以本轮使用已有画图窗口的真实前台切换。没有把这等同于完整 Win+R→mspaint 启动路径验收；该具体入口保留 pending。本轮修复与已通过路径可发布到开发主线，不表示全部重建功能已完成。测试记录/截图/日志不入 Git。
