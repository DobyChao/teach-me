# T01 · 工程与领域控制器

日期：2026-10-17；Windows，Node.js 24.18.0，npm 11.16.0。

`npm run check`：规划校验、模块边界、Prettier、32 项测试、tsc 和 Vite/Electron 构建通过。本机沙箱拒绝回环网络连接，涉及本地 HTTP API 的测试在获准的沙箱外执行；未修改测试来跳过该失败。

领域行为覆盖：记原窗口→截图→聚焦顺序，截图中取消、过早提交、失败重试、重复提交、wait/ack/重发、并发 wait、取消后的迟到转写、语音撤回和定时提交、图元/crop 坐标、HTML 限制、会话清理范围、本地 ASR 临时文件删除及本机 API 转写。

这证明工程与控制器行为，不证明真实桌面采集、外部窗口焦点、麦克风识别或多屏矩阵。后者在对应任务中单独验收。
