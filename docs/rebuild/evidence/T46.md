验证：`test/hotkeys.test.ts`四项——归一化大小写/空格/别名、拒绝裸键/未知token/重复修饰键/多主键、schema默认值+归一+冲突拒绝、旧设置文件迁移与非法热键拒绝；npm run check（plan/context/boundaries/format/130项测试/构建）通过。开发中两次自纠：CmdOrCtrl期望值按Windows归一修正；单测数据撞continue默认键N改用J。
