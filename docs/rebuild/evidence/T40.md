# T40 · 取消在途本地与自定义转写

2026-10-21。本轮纯Node观察确认：voice.cancel后local识别进程未kill、临时音频仍保留，custom请求signal未abort；20秒期限到达才清理，迟到文本被generation过滤，没有证据表明永久挂起或串稿。

目标：控制器为每次转写提供取消信号，host将其传给local/custom；预取消或写入中取消不得再启动识别器/上传，本地已启动则终止本轮child并在close后清文件，custom请求和响应体读取受同一取消信号约束。保留原20秒执行期限，本地终止后等待close最多5秒；旧取消/回调不能碰新任务。

本轮只运行模拟进程/网络的Node测试及静态构建；需先旧版失败对照、正常/取消/超时相邻回归、独立审查与check。Windows本地命令、麦克风及真实API的取消行为仍pending。

实现：VoiceController每次stop独立AbortController，cancel先失效代次再abort；旧stop的finally只能清自己的controller。host沿原音频等待通路传signal，transcribe入口、mkdir后和写入后检查取消。custom合并主动取消与20秒期限，覆盖fetch及body；local取消/超时/输出超限统一终止本轮child，close后清文件，无close最多等5秒再尝试清理。
