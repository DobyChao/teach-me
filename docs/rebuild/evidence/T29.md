## 规则案例审阅

以下为人工规则审阅，未启动独立Agent，也未实际调用宿主hook：

| 场景 | 应有选择 |
| --- | --- |
| 当前会话有可用且验证通过的原生通路 | 自行选择，处理输入后交还该机制，不并发wait |
| 环境提供受支持的会话级接通设施 | 可就地接通并验证，不强制另开任务或找专用适配器 |
| 只发现hook功能，尚不能把App输入送回当前对话 | 保持wait兜底，不能假定空闲会被唤醒 |
| 无合适设施、无法验证或接入不合适 | 用一个wait，不按宿主名字盲选 |
| 原生通路失败 | 先停旧消费者，保留待处理消息，再降级wait |
| 教学停止或会话结束 | 清理会话级监听，停止等待 |
