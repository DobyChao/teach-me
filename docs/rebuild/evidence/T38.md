# T38 · 语音取消重试隔离

2026-10-21。认领本轮连续输入可靠性目标：取消旧识别后立即重试，旧进程/异步回调不得停止新设备、串入旧转写或改写新错误；取消与失败必须及时结算。

用户本轮禁止实机测试，使用纯Node FakeChild、受控Promise与模拟时钟，不启动Electron/PowerShell/麦克风。验收为旧实现确定性失败、新实现相同场景通过、相邻正常/异常路径回归、独立审查与check；Windows麦克风/焦点实际验收保留pending，任务不标全部完成。

独立只读审查已复现：旧stop等待退出后finally全局abort杀新进程；旧启动8秒计时器杀新进程；fail在await cancel期间新录音开始后将旧错误写入新id。修复与结果收尾补充。

实现：系统识别的文本、完成Promise与取消闭包属于各自child；abort立即清启动期限并拒绝该轮ready/done，stop持有本轮清理闭包。旧回调只能结算/清理旧child；未READY即exit 0也报告启动失败。控制器忽略过期start完成，失败清理后重验代次再写error。stop写管道放入finally保护范围。没有改变识别引擎、确认期限或输入面。

验证：新增控制器2项旧实现失败（原6项通过），新增系统识别8项旧实现3通过/5失败；修复后合计16项通过。覆盖正常分包READY/转写/stop、旧stop退出与旧启动超时、取消及时结束start/stop、未READY退出、多轮失败恢复、启动/停止超时，以及新录音不被旧错误覆盖。所有SystemSpeech spawn由FakeChild替换，计时器模拟；失败日志在忽略的.runtime/t38-voice-before.log与t38-speech-before.log，回归源码随提交保留。npm run check通过94项测试、规划/上下文/边界/格式、类型与构建。独立审查发现首版清理child后stop吞掉READY后的真实故障；已用新测试复现并改为返回本轮done，ERROR/非零exit/process error三条均保留原故障。修正后17项语音测试通过，最终完整check结果见下。
