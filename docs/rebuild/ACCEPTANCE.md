# 验收场景

表内“自动”不代表已经实现；具体执行结果以任务证据为准。

| 编号 | 场景与预期 | 验证方式 |
| --- | --- | --- |
| A01 | 所有需求被任务引用；任务依赖无环；done 具有完成证据 | 自动：check-plan |
| A02 | waiting/ready 显示继续；thinking/offline/ended、录音、非空草稿隐藏继续；箭头或 HTML 单独存在时可清除/隐藏 | 自动：领域测试 |
| A03 | 收起/展开保留同一输入实例、草稿和选择；四层布局、冷灰 token、长文本/工具满载无裁切 | 组件测试 + 浏览器视觉，520/460 宽 |
| A04 | 鼠标与快捷键进入输入：先记原窗口与截图再聚焦；发送/取消恢复正确外部窗口；已关闭原窗口不误激活其他窗口 | Windows 真机 + 时序证据 |
| A05 | 截图未完成时发送、取消、连发、结束会话；旧回调不得污染新 turn；发送失败保留草稿、重试只投递一次 | 控制器/协议测试 + 真机 |

| A07 | 箭头/框/HTML/笔迹可独立清除、隐藏恢复；不拦截目标软件鼠标；用户笔迹不被 clear 默认清掉 | 协议测试 + Windows 真机 |
| A08 | ask 立即审批；lesson 可打断读秒；always 直接截图；拒绝、超时、失败重试不抢焦点 | 控制器测试 + Windows 真机 |
| A09 | 快按/长按分流；麦克风授权未完成即松手、取消后晚返回、连续录音、转写错误均停止设备且可重试；1–2 秒内可撤回 | 异步测试 + Windows 真机 |
| A10 | 设置持久化、热键冲突反馈、三步引导走真实协议可跳过；离线/无会话关闭可退出 | 集成 + Windows 真机 |

| A13 | npm ci 可复现；类型/测试/构建通过；Windows 安装包可启动；旧入口切换有回退说明 | CI + Windows 安装包验收 |

## 证据格式

每份 evidence 写明任务、日期、环境、命令与结果、自动/视觉/真机各自范围、未验证项。截图/录音不提交；确需视觉证据先去除真实屏幕与个人数据，优先使用合成 fixture。失败结果同样记录，不能用“后续用户验收”结束一个标 done 的真机任务。
