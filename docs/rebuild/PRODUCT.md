## 明确纠正的历史歧义

- Agent 正在 `wait` 表示可接收用户回应，不代表麦克风在听，也不因此隐藏继续按钮（ADR-002）。
- “有 Agent 内容”包含箭头、框、spotlight、HTML、笔迹，不能只看画板笔迹数组（ADR-002）。
- 原软件焦点必须在面板激活前保存；鼠标入口需宿主方案验证。只在 textarea 的 focus 回调里读前台窗口不满足 R03（ADR-003）。
- 对话内容只来自 `say/show`；状态与语音实时转写是有标识的本地信息，不能伪装 Agent 发言。
- 没有会话或已结束时的关闭动作退出应用；活跃会话先结束教学，再可退出。

## 本轮范围

从空分支实现规划基础、React 面板与真实 Electron/CLI 文字链路。实现和验收分开记录，未通过真机验证不宣称可交付。桌宠形象沿用自带资产，具体尺寸与动画在视觉验收时确定。

## 暂不做

代点击/键入、多个活跃教学、挂起恢复、Agent 宿主命令审批转发、云端账号系统、完整辅助功能树定位。多屏仅允许一个教学屏，不做跨屏连续画布。
