# 面板小、中、大三档

2026-10-18，依据用户提供的双入口小胶囊图与三档切换要求。以下为本项目的交互决议，不声称复刻 Codex 内部规则。

| 档位 | 尺寸（DIP） | 内容与入口 |
| --- | --- | --- |
| 小 mini | 120×48 | 写字、语音两个入口，左侧小把手可拖；保留冷灰/粉色 token。新回复或草稿通过入口提示保留可发现性 |
| 中 compose | 宽360，高约76，随多行/工具/错误增高 | 唯一输入框、状态、画板/语音/发送；更多工具按需打开；上箭头进入大号，横线回小号 |
| 大 conversation | 宽520，内容高度240–560 | 对话、继续建议、连接/截屏审批、设置；下箭头回中号，横线回小号 |

## 切换规则

| 触发 | 结果 | 保护条件 |
| --- | --- | --- |
| 启动 | 小 | 热键等需用户处理的错误至少中号可见 |
| 点击写字、短按语音、输入快捷键 | 至少中 | 已在大号则保留大号；先取图后聚焦的事务不变 |
| 按住说话 | 至少中 | 复用原录音按钮与 Pointer Capture，录音、转写、撤回期都不自动缩小 |
| Agent say/show | 大 | 正在输入、有草稿、录音或拖动时保留当前档位并标记新回复，主动展开后消标记 |
| 连接、选屏、截屏审批；设置 | 大 | 审批未决不允许回小/中，不抢输入焦点 |
| 主动收小 | 小，草稿仍保留 | 正在取图/发送/录音或有审批时不收；普通编辑先取消当前输入事务、恢复原软件焦点 |
| 空闲 | 小 | 无草稿、无输入事务、无录音、无错误、无审批、无设置/更多工具/画板编辑；鼠标不在面板，窗口也没有焦点 |
| 悬停/鼠标离开 | 不自动展开 | 离开只重新开始空闲计时，避免鼠标扫过触发窗口变化 |

空闲延迟沿用“自动收起秒数”，默认8秒，0关闭。大号阅读新回复时至少留出 `文字数/18` 秒，最长30秒；设置更长时遵循设置。发送成功清草稿，取消保留草稿，因此取消不意味着自动收小。

## 动效与窗口

切换在同一 BrowserWindow 内完成，200ms cubic ease-out 同时调整 x/y/宽/高，保持右下锚点；内容暂时淡化再恢复，过渡中保留内容轮廓。ResizeObserver 的尺寸只在静止后的当前档位应用，旧档报告无效；textarea在动画结束后重算高度，避免按过窄的过渡宽度增高。新切换可从当前窗口尺寸继续，拖动前结束未完成的尺寸动画。拖动位置沿用 ADR-012 的本地保存。

系统 `prefers-reduced-motion` 为 reduce 时跳过尺寸与淡入动画。Windows `setBounds` 的 animate 参数不能提供此动画，因此由宿主定时插值，禁止用 hide/show 或重建原生窗口实现过渡。

## 验收边界

纯状态规则、Electron 实际 DOM/窗口中间帧和 Windows 鼠标观察分别记录。自动帧证据不等于流畅度、真实麦克风和多屏缩放验收。相关任务为 T17，历史两档 T16 的跨屏限制继续保留。
